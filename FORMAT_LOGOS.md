# Format marks

Bundled vector paths reproduce the published format marks, tinted to match the source badges.

- Dolby double-D mark: https://commons.wikimedia.org/wiki/File:Dolby.svg (Dolby, via music.dolby.com; geometric logo/public domain).
- Dolby Vision: https://commons.wikimedia.org/wiki/File:Dolby_Vision_(logo).svg
- HDR10+: https://commons.wikimedia.org/wiki/File:HDR_10_plus_logo_(black).svg

Trademarks belong to their respective owners. Plain HDR and HDR10 remain text badges; the unrelated sun icon is not used.
